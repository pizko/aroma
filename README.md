# Aroma

Демонстрационный сайт компании «Орлан»: каталог аромапродукции, бренды, контрактное производство и парфюмерное ателье.

Сайт собран как статический проект и опубликован через GitHub Pages.

## Источники контента

- https://opt-aroma.ru/
- https://whispy.ru/
- https://byhanna.ru/

Фотографии используются с разрешения поставщика. Тексты переработаны для нового сайта.

## Как устроены две копии

- **pizko/aroma** (этот репозиторий) — **точка сохранения**: сюда переносится состояние,
  которое одобрено. Отсюда ничего не правится напрямую.
- **pizko/aroma-redesign** — рабочая копия: там идёт доработка, там же её видно
  на pizko.github.io/aroma-redesign (закрыта от индексации).

Перенос 23.09.2026: сюда перенесены страницы, стили, скрипт и фотографии
из рабочей копии. Различаются только адреса `canonical`, `robots` (здесь индексация открыта),
`robots.txt` и `sitemap.xml` — они свои у каждой копии.

Что вошло в перенос: блок трёх направлений на главной, фильтр по брендам и поиск в каталоге,
редакционный разворот на странице СТМ, редакционный ввод на странице ателье, хлебные крошки
и `BreadcrumbList` на внутренних страницах, восстановленные фотографии ателье
(`hanna-3.jpg`, `hanna-4.jpg`) и исправленный горизонтальный сдвиг каталога на узком экране.
Подробности — в README рабочей копии.
